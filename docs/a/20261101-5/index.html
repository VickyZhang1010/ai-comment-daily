一扇窗口的连接

开篇立论 → 逐层论证 → 结尾收束
开篇立论

在综治中心大厅，有一块标着“检察服务窗口”的标识牌，这里每天人员众多，上演着群众间的各种矛盾、纷争。每天早上八点半，我准时打开接待窗口，桌上摆好来访登记表，脑中先过一遍昨天未解决的来访问题，想一想今天该从何处着手。然后坐下来等，等来的往往不是“案子”，而是需要分流引导、协同处置的群众诉求。

入驻综治中心两年多，我经手的咨询和纠纷调解占了接访台账的绝大多数，真正属于检察机关管辖的屈指可数。起初我也困惑过：一个法律监督机关的工作人员，坐在这里处理邻里纠纷和劳务纠纷等问题，这算不算“不务正业”？后来我逐渐明白，检察为民关键在于依规履职、协同联动，既不缺位，也不错位，还不越位。窗口不大，连接的却是治理链条上的一环。

早上刚开门，一位大姐就推门进来，手里攥着一沓皱巴巴的纸，纸边被攥得发软。她丈夫在务工中受伤，劳务关系和相关责任一时说不清，她不知道该找谁。说到一半，眼眶就红了。我先递了纸巾，说：“您慢慢说，我好好听。”我仔细看了材料，经了解，该事项不在检察机关直接办理范围，按规定应引导至劳动监察部门。但我没有这么做。我帮她把关键信息整理出来，写清了事发地点、时间、用工方基本信息和联系方式，又打电话帮她联系了劳动监察窗口。她走的时候连声道谢。

在控申窗口待久了会发现，很多来访群众其实并不清楚检察院是干什么的。他们来到这里，只是因为“出了事不知道找谁”。一位大爷因为邻里噪声影响自己休息，找过村委会、找过司法所，最后抱着试一试的心态走进了综治中心。还有一位老人对案件处理不理解，反复来窗口倾诉。我耐心听取，结合案件已生效处理情况做好释法说理和情绪疏导。面对这些来访者，如果简单告知“不符合受理条件”，程序上没错，但他们的心结不会因此解开。很多时候，群众需要的不仅是一个法律答案，更是一个愿意认真听他们把话说完的人。话说完，气也就顺了一些。

午饭过后，来访的人少了些，大厅里空出几排椅子。一位中年男子推门进来，情绪很激动。他在一家私营企业干了三个月，遇到劳务费拖欠，对诉讼程序和法律援助渠道不熟悉。他问我：“你们检察院能不能帮我要回工资？”该事项不由检察机关直接办理。我结合《保障农民工工资支付条例》给他讲了维权路径，告诉他可以申请法律援助，又帮他联系了综治中心的调解员和司法局的驻点律师。他临走时说了一句让我印象很深的话：“本来觉得来错了地方，没想到你还真帮我想了办法。”

下午，一对邻居因为琐事起了争执，闹到了综治中心。说实话，这类纠纷在我们接访台账里并不少见，看似不属于检察机关直接办理事项，但处理不好就可能升级为治安案件甚至刑事案件。我没有急着讲法条，而是先请他们分开坐下，各自把话说透。等双方情绪平复了，再从民法典相邻关系的角度帮他们厘清权利义务。最终双方握手言和。临走时一位当事人回头说：“其实也不是多大的事，就是憋了一口气。”

这些事写进台账，只是几行记录，但对当事人来说，可能就是生活能不能回到正轨的分界线。

天色渐暗，综治中心其他窗口陆续关了灯，走廊里的脚步声稀疏下来。我还在整理当天的来访记录。翻看台账，今天接待的来访群众，事项多是劳务咨询、邻里纠纷、法律咨询等基层常见诉求。

有人可能觉得，这样的工作平淡无奇，写不出什么精彩的故事。但我不这么看。检察机关入驻综治中心，重点不在于办多少“大案”，而在于在综治中心统筹下做好分流引导、协同联动，把法律监督的触角延伸到基层治理的“神经末梢”，推动矛盾纠纷解决在初始阶段、化解在萌芽状态。

结尾收束

一位来访者在临走时说：“你们检察院的人态度真好，虽然事情最后没在你们这儿解决，但我知道该找谁了。”这句话让我觉得，这扇窗没有白开。我送他到门口，回来把这条记录补进台账。窗口的工作，大多是这样一天一天过来的。
