求是网评论员：两个答案何以贯通

开篇立论

党的二十届五中全会通过的《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》深刻总结百余年奋斗历史经验，强调我们党“在依靠自身力量和人民支持解决自身问题中不断强大”。从“让人民来监督政府”到“自我革命”，两个答案既一脉相承又与时俱进，体现了我们党对长期执政规律认识的不断深化。自身力量与人民支持相互贯通，揭示了中国共产党能够不断解决自身问题、始终保持先进性和纯洁性的内在机理。深刻把握这一辩证关系，是学习贯彻全会精神的应有之义。

自身力量与人民支持之所以高度统一，根本在于党的性质宗旨。中国共产党为人民而生、因人民而兴，始终代表最广大人民根本利益，没有任何自己特殊的利益，从来不代表任何利益集团、任何权势团体、任何特权阶层的利益。不谋私利就能谋根本、谋大利，就敢于检视自身、常思己过，不讳疾忌医、不文过饰非，做到凡是有利于人民的就坚持，凡是不利于人民的就改正。党性和人民性从来都是一致的、统一的，对党忠诚的本质要求是不负人民，不负人民是对党最大的忠诚。党同人民风雨同舟、生死与共，人民就从党的性质宗旨和实际行动中认识党、信任党、支持党。党推进自我革命，目的在于永葆先进性和纯洁性、更好为人民谋幸福；人民拥护和支持党，根基在于党始终代表人民根本利益、全心全意为人民服务。自身力量与人民支持由此统一于党的初心使命，统一于党同人民群众的血肉联系，既为党推进自我革命确立价值坐标，也为党解决自身问题凝聚深厚力量。

依靠自身力量解决自身问题，体现了我们党正视问题、修正错误的高度自觉。党的自我革命有着明确内涵，就是刀刃向内，全面从严治党，保持党的先进性和纯洁性，实现党的自我净化、自我完善、自我革新、自我提高。事物在矛盾运动中发展，一个长期执政的大党，重要的是以高度自觉认识矛盾、解决矛盾，在解决矛盾、破解难题中推动自身建设不断向前。百余年来，我们党勇于坚持真理、修正错误，在革命、建设、改革各个历史时期，针对自身存在的突出问题，采取一系列有力措施，进行有效整治。特别是新时代以来，以习近平同志为核心的党中央以巨大的政治勇气和强烈的责任担当，坚定不移全面从严治党。从制定和落实中央八项规定开局破题，到坚定不移一体推进不敢腐、不能腐、不想腐，再到健全全面从严治党体系，集中体现了党刀刃向内、刮骨疗毒的历史主动。正是这种自觉和主动，使党能够不断清除侵蚀健康肌体的病毒，始终保持旺盛生命力和强大战斗力。

人民支持为党解决自身问题提供坚实依托和检验标尺。坚持群众是真正英雄的历史唯物主义基本观点，就要尊重人民主体地位，积极发展人民民主，充分发挥人民的积极性主动性创造性。党的根基在人民、血脉在人民、力量在人民。党内存在哪些问题，哪些问题最为突出、最需解决，人民群众有着直接感受和真切判断。人民群众中蕴藏着治国理政、管党治党的智慧和力量，广泛凝聚这种智慧和力量，党就能从人民的实践经验和社会反响中深化对自身问题的认识。我们党每次开展整风整党和集中教育，都在认真进行自我教育的同时，让群众参与，虚心向群众请教，接受群众监督，认真解决群众反映强烈的党内突出问题。新时代以来，持续整治群众身边不正之风和腐败问题，推动解决群众急难愁盼问题，以实际成效回应人民关切、增进人民福祉，充分体现了管党治党与凝聚民心的相互促进。把群众意见转化为发现问题的重要线索，把群众评价转化为检验成效的重要依据，把群众创造转化为改进工作的重要资源，党解决自身问题就能更好找准方向、抓住要害。

结尾收束

学习贯彻全会精神，要把自身力量与人民支持的辩证统一转化为内外贯通的实践。内靠全面从严治党、推进自我革命，就要紧紧扭住管党治党责任制“牛鼻子”，推动各级党组织和党员干部知责担责、履职尽责，使发现问题、纠正偏差、推动整改、促进治理贯通起来。外靠发展人民民主、接受人民监督，就要走好新时代党的群众路线，落实涉及民生重大决策征求群众意见制度，畅通群众监督渠道，推动党内监督同各方面监督深度融合、高效联动。自身建设越有力，人民对党的信任就越深厚；人民支持越充分，党解决自身问题就越有成效。这种内外贯通，使党始终充满生机活力，使人民对党的信任拥护转化为推进中国式现代化的共同意志和共同行动。始终坚持以自身建设赢得人民信任、以人民支持促进自身建设，我们党必将在依靠自身力量和人民支持解决自身问题中不断强大，不断开创新时代管党治党、兴党强党新局面。
