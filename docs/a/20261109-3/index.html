不明来历的快递，为何被送到人们手中

光明日报 · 光明时评 · 查看原文 · 结构度 90 · 613 字
开篇立论 → 逐层论证 → 结尾收束
开篇立论

首先，这暴露出个人信息保护的漏洞。不明来历快递泛滥，一个很重要的原因就是个人信息沦为他人“囊中之物”。究其根源，既有个人过度分享、单据处理不当、网络使用不当等原因，也有黑客、黑产团伙、行业内鬼作奸犯科等因素。只有为个人信息加上一把“锁”，严格加以保护，这些虚假快递才会失去靶标，此类骗局也才能减少。

其次，也反映出快递企业存在不规范操作。根据邮政法、快递暂行条例等法规，快递企业有安全查验的义务，必须落实‌收寄验视与实名收寄‌制度，对客户身份进行查验，对寄递物品进行安全检查或开封验视。对于禁止寄递、存在重大安全隐患或客户拒绝查验的物品，不得寄递。而不明来历快递毫无障碍地抵达客户端，暴露出快递企业的“把关”形同虚设。对于那些大批量、来源可疑的寄件，还需要快递企业严格核验寄件人真实身份信息，防止骗局“一路绿灯”。

此外，打击不明来历快递，监管主体须压实责任。骗子先是诱导收件人扫码、添加账号，再利用私域社群开展虚假宣传活动，推销违规保健品。在此过程中，相关平台被用于引流营销和实施诈骗，对此，平台应当完善风控，识别批量添加好友、养生洗脑课程、违规保健品推销账号，及时处置封禁；监管部门则应根据举报和线索顺藤摸瓜，对背后的违法主体进行严肃查处，不断压缩此类违法活动的生存空间。

结尾收束

不明来历快递损害公众合法权益，也扰乱物流秩序，必须严厉打击。只有多方形成合力，保护个人信息，落实查验制度，强化监管责任，才能有效治理此类骗局。（欧阳晨雨）
