孩子也要有健康的“边界感”

法治日报 · 第03版 政法 · 查看原文 · 结构度 77 · 1842 字
开篇立论 → 逐层论证 → 结尾收束
开篇立论

人与人交往，离不开清晰的边界。健康的边界感能够保护个人的心理安全、情感稳定和身体隐私，避免在关系中被过度消耗、控制或侵犯。无论是健康的心理状态，还是对社会规则的理解与适应，都需要边界感。它既关系到成年人的相处方式，也适用于孩子之间的交往，更无时无刻存在于亲子关系互动中。

前不久，天气转凉，我和几位朋友带着各自的孩子到民宿小住。民宿配有泳池，阳光把池水晒得温热，但户外气温依旧偏低。一个孩子兴致勃勃地下水，玩水枪、打水花，十分开心。这时，另一个小男孩被这一幕所吸引，也想要下水玩耍。但不巧的是，他感冒还没好，此时下水，显然有健康风险。于是，他把乞求的眼神投向了自己的妈妈：“哥哥在玩水，我也想玩……”

作为旁观者的我，原以为这位妈妈会和孩子解释不能下水的原因。但意料之外的是，孩子的话音刚落，她冲着泳池里玩得正欢的孩子大喊：“快上来吧！你再玩，弟弟也想玩。他已经感冒了，不能玩水。”

更令人意外的是，泳池里孩子的家长听到这番话，竟然也和朋友一起劝自己的孩子“为了弟弟”不要继续玩水了。我猜，她可能觉得，既应该给朋友一个面子，也得顾及另一个孩子的心情。但她自己的孩子，显然并不愿意放过秋日里难得的戏水机会，嘟囔着：“我还想玩呢。”

虽然这只是旅途中的一件小事，但它却至少暴露出了四个关于边界的问题：孩子行为的边界、孩子之间的边界、成年人交往的边界，以及家长与孩子之间的边界。

先看孩子行为的边界。泳池边的孩子能不能下水，取决于他是不是想下水玩以及对自身安全、健康因素的考量。至于泳池里有其他孩子在玩，并不应该成为他下水的理由。当然，我们完全可以理解一个孩子因为看到其他孩子玩得开心，进而被这种情绪感染，产生想要下水玩的想法。但是，随着孩子年纪渐长，也要逐渐看到自身和环境里的更多因素，这是学会理解边界感，为自己负责的必要练习。

接着看孩子之间的边界。如果因为其他人做了，自己就跟着去做，某种程度上说，这是盲从。日常生活中，有的孩子会说，其他孩子有某件玩具，所以自己也想要。但真的得到了这件玩具，却并不见得有多喜欢。在类似的事件里，孩子们往往是把目光向外投射，而不是聚焦在自己内心的真实感受上，这就很容易养成受他人影响的惯性。而换作是泳池里那个孩子的视角，这种边界感也很值得思考：自己本来玩得开心，却被告知因为要照顾弟弟的感受而停止玩耍。他会如何作想呢？他自己的感受不重要吗？

再看成年人交往的边界。“泳池”事件看似是两个孩子的事，却因为家长的参与也加入了成年人的思维。是站在对孩子成长有益这边，还是站在“人情世故”或是“朋友面子”这边？别忘了，成年人的交往方式，也是孩子眼中的“模板”。如果成年人没有边界感，如何让孩子理解呢？

最后看家长与孩子之间的边界。担心孩子下水着凉，这种想法再正常不过，也不妨坦诚地告诉孩子自己的担心。但解决“下不下水”问题的人，应该是孩子自己。同样，作出“上不上来”这一决定的人，也应该是孩子自己。时至今日，仍有不少家长存在一种固有认知：只要别的孩子——尤其是年龄较小的孩子提出需求，自家年龄稍大的孩子就应当让步。强迫孩子放弃自己的乐趣去成全别人，并不是在培养善良，而是传递一种错位的观念：自己的感受不重要，他人的需求优先于你的意愿。长期处在这样的环境，孩子会误以为自己的喜好可以被随意剥夺。长此以往，孩子容易习惯性委屈自我，不懂拒绝，更难以主动维护自身的合理权益。

孩子们的人生还很长。在他们走向独立之前，有无数真实的场合供他们处理各种各样的关系。随着年龄增长，他们也需要有更多机会、更多自主权去实践边界感这一人生课题。

未成年人保护法第十九条明确：“未成年人的父母或者其他监护人应当根据未成年人的年龄和智力发展状况，在作出与未成年人权益有关的决定前，听取未成年人的意见，充分考虑其真实意愿。”由此可见，尽管未成年人属于限制民事行为能力人，心智尚未完全成熟，监护人负有审慎筛选、引导保护的法定责任，但法律也认为孩子拥有表达自身意愿的权利。

尊重意愿不等于放任纵容，守护边界也绝非教孩子变得自私冷漠。家长可以引导孩子看见同伴的失落，共情他人的处境，但不必用牺牲孩子的正当权益为代价。无论是退让还是分享，应当发自孩子的本心，而不应来自外界的逼迫。

结尾收束

成年人要先守住自己的人际关系边界，同时也要守住亲子之间的边界，不随意替孩子做取舍。我们的示范，会慢慢内化为孩子待人接物的标尺。我们也要相信，孩子需要一次又一次的练习，才能够学会健康的边界感，并在这个过程中不断积累处理各种关系的智慧与勇气。
